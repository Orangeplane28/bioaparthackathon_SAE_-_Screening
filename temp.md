The project I'm most proud of is a production RAG chatbot I built for the IIT Madras BS programme's student activities platform, serving over 40,000 students - and Claude Code was central to how I pulled it off.
The scope was significant: hundreds of documents across wildly different formats - PDFs, Excel sheets, Google Docs, published pages, images - all needing to be parsed, chunked, and kept in sync with a live Qdrant vector store. Claude Code helped me move fast without cutting corners. I used it to design and iterate on the ingestion pipeline (Docling-powered, with hash-based delta sync so only changed chunks ever hit the vector store), architect the multi-layer query pipeline, and write the Redis caching logic with NER-gated key matching - because in an academic context, swapping one named entity in a query can flip the answer entirely.
What I'm proudest of isn't any single component - it's that the system actually works at scale with low latency and low cost. Claude Code let me think at the architecture level while handling the implementation details quickly: the sparse + dense Qdrant retrieval with RRF, the post-retrieval cache check on (query, retrieved_doc_ids), the reverse index for cache invalidation, versioned chunking for future strategy upgrades. Features that would have taken days to get right I was shipping and testing in hours.
Leading a team on this while using Claude Code also changed how I delegate - I could prototype a component, reason through it clearly with Claude Code, and hand off something well-structured rather than just a rough sketch.
